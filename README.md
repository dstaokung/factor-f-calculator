# โปรแกรมคำนวณค่า Factor F งานก่อสร้าง

### 👉 เปิดใช้งาน: **https://dstaokung.github.io/factor-f-calculator/**

เว็บแอปหน้าเดียว (single-file HTML) สำหรับหาค่า **Factor F** ของงานก่อสร้าง ตามตารางแนบท้ายหนังสือกรมบัญชีกลาง
**ด่วนที่สุด ที่ กค 0433.2/ว 481 ลงวันที่ 26 มิถุนายน 2569** (อัตราดอกเบี้ยเงินกู้ร้อยละ 6 ต่อปี, VAT ร้อยละ 7)

> ทำงานได้ทั้งแบบเปิดออนไลน์และดับเบิลคลิกเปิดไฟล์ตรง ๆ ไม่ต้องติดตั้งอะไร ไม่ต้องมีเซิร์ฟเวอร์ ไม่ส่งข้อมูลออกนอกเครื่อง

---

## ความสามารถ

- ครอบคลุม **4 ประเภทงาน × 12 ตาราง = 48 ตาราง** ตามต้นฉบับ
  - งานก่อสร้างอาคาร (24 ช่วงค่างาน)
  - งานก่อสร้างทาง (36 ช่วงค่างาน, มีคอลัมน์ฝนชุก 1 / ฝนชุก 2)
  - งานก่อสร้างสะพานและท่อเหลี่ยม (40 ช่วงค่างาน)
  - งานก่อสร้างชลประทาน (40 ช่วงค่างาน, มีคอลัมน์ฝนชุก 1 / ฝนชุก 2)
- เลือกอัตราเงินค่าจ้างล่วงหน้า (0/5/10/15%) และอัตราเงินประกันผลงาน (0/5/10%)
- เลือกคอลัมน์ตามลักษณะแหล่งเงิน — ต้องชำระ VAT (`Factor F`) หรือไม่ต้องชำระ VAT (`รวมในรูป Factor`)
- **เทียบอัตราส่วน (Interpolation) อัตโนมัติ** เมื่อค่างานอยู่ระหว่างช่วงในตาราง
- **แสดงวิธีการหาค่า Factor F ทีละขั้น** พร้อมสูตรและตัวเลขจริงทุกบรรทัด
- **แนบตาราง Factor F ฉบับเต็มของเงื่อนไขที่เลือก** พร้อมไฮไลต์แถวและคอลัมน์ที่นำมาใช้
- **แนบสำเนาหน้าตารางต้นฉบับจาก PDF** ของเงื่อนไขที่เลือก (48 หน้าใน `pages/`) — พิมพ์ออกเป็นหน้าสุดท้าย
  พร้อม **ไฮไลต์ช่องค่า Factor F ที่หยิบมาใช้จริงลงบนภาพสำเนา** (กรณี interpolation จะไฮไลต์ทั้งสองแถวที่คร่อมอยู่)
- **แนบสำเนาหนังสือเวียน ว 481 ต้นฉบับ** (`pages/letter-w481.jpg`) พิมพ์ออกเป็นหน้าที่ 2 (ปิดได้ด้วยช่องติ๊กในหน้าเว็บ)
- **ออกแบบหน้าพิมพ์ A4 มาโดยเฉพาะ** — ใบสรุป 1 หน้า + สำเนาหนังสือเวียน 1 หน้า + สำเนาตารางต้นฉบับ 1 หน้า

## วิธีการคำนวณที่ใช้

1. เลือกตารางจาก *ประเภทงาน* + *อัตราเงินค่าจ้างล่วงหน้า* + *อัตราเงินประกันผลงาน* (ตารางที่ 1/12 – 12/12)
2. เลือกคอลัมน์จาก *ลักษณะแหล่งเงิน* และ *พื้นที่ฝนชุก*
3. แปลงค่างานต้นทุนเป็นหน่วยล้านบาท
4. หาแถวหรือช่วงค่างานที่คร่อมอยู่
5. ถ้าอยู่ระหว่างช่วง ให้เทียบอัตราส่วนเชิงเส้น

```
R = (ค่างาน − ค่างานแถวล่าง) ÷ (ค่างานแถวบน − ค่างานแถวล่าง)
F = Fแถวล่าง + (Fแถวบน − Fแถวล่าง) × R
```

**ทุกขั้นตอนใช้ทศนิยม 4 ตำแหน่ง โดยตัดทิ้งตำแหน่งที่ 5 (truncate) ไม่ใช่ปัดเศษ**

กรณีค่างานต่ำกว่าหรือเท่ากับแถวแรก และกรณีสูงกว่าแถวสุดท้าย ให้ใช้ค่าในแถวนั้นโดยตรง ไม่ต้องเทียบอัตราส่วน

## ข้อมูลตาราง

- `data/factor-f-v481.json` — ข้อมูลตารางทั้ง 48 ตารางในรูป JSON สำหรับนำไปใช้ต่อ
  (ตัวแอปฝังข้อมูลชุดเดียวกันไว้ใน `index.html` แล้ว จึงไม่ได้เรียกไฟล์นี้ตอนทำงาน — ทำให้เปิดจากไฟล์ตรง ๆ ได้โดยไม่ติด CORS)
- `pages/<ประเภทงาน>-<ล่วงหน้า>-<ประกันผลงาน>.png` — สำเนาหน้าตารางต้นฉบับ 48 หน้า
  แปลงจาก PDF ที่ 110 dpi ขาวดำ (เช่น `pages/building-10-5.png` = งานอาคาร ล่วงหน้า 10% ประกันผลงาน 5% = ตารางที่ 8/12)

พิกัดกรอบไฮไลต์เก็บอยู่ใน `index.html` (ก้อน `ffboxes`) เป็นตำแหน่งสัมพัทธ์ 0–1 ของภาพแต่ละหน้า
คำนวณจากพิกัดข้อความจริงใน PDF จึงตรงช่องเสมอไม่ว่าจะย่อขยายภาพแค่ไหน — เก็บแยกเป็น “ขอบเขตคอลัมน์” กับ “ขอบเขตแถว” จึงใช้เนื้อที่รวมเพียง 30 KB

โครงสร้าง:

```jsonc
{
  "meta":  { "doc": "...", "date": "...", "interest": 6, "vat": 7 },
  "types": {
    "building": {
      "name":   "งานก่อสร้างอาคาร",
      "cols":   ["รวมในรูป Factor", "Factor F"],
      "labels": ["≤0.5", "1", "2", "...", ">500"],  // ข้อความในคอลัมน์ค่างาน
      "xs":     [0.5, 1, 2, ..., null],             // ค่าตัวเลขของแต่ละแถว (null = แถวปลายเปิด)
      "tables": { "0_0": [[...รวมในรูป Factor...], [...Factor F...]], "0_5": [...] }
    }
  }
}
```

คีย์ของตารางคือ `"<อัตราเงินค่าจ้างล่วงหน้า>_<อัตราเงินประกันผลงาน>"` เช่น `"10_5"`

### การตรวจสอบความถูกต้อง

ค่าทุกตัวถอดจากไฟล์ PDF ต้นฉบับด้วยการอ่านพิกัดข้อความ (ไม่ใช่การพิมพ์ตามมือ) แล้วตรวจซ้ำสองชั้น

- เทียบค่าทุกช่องกับข้อความที่สกัดจาก PDF อีกรอบหนึ่งแบบอิสระ
- ตรวจความสัมพันธ์ `Factor F ≈ รวมในรูป Factor × 1.07` ทุกแถวของทั้ง 48 ตาราง
  (มี 4 ช่องในงานอาคารที่ต่างจากสูตร 0.0001 เนื่องจากการปัดเศษในเอกสารต้นฉบับเอง — โปรแกรมนี้ยึดตามตัวเลขที่พิมพ์ในต้นฉบับ ไม่ได้คำนวณใหม่)

## หมายเหตุสำคัญ

1. กรณีค่างานอยู่ระหว่างช่วงของค่างานต้นทุนที่กำหนดในตาราง ให้เทียบอัตราส่วนเพื่อหาค่า Factor F
2. ถ้าเป็นงานเงินกู้หรือจากแหล่งอื่นซึ่งไม่ต้องชำระภาษีมูลค่าเพิ่ม ให้ใช้ค่าในช่อง “รวมในรูป Factor”
3. คอลัมน์ “ฝนชุก 1” และ “ฝนชุก 2” มีเฉพาะงานก่อสร้างทางและงานก่อสร้างชลประทาน และต้นฉบับกำหนดไว้เฉพาะกรณีที่ต้องชำระภาษีมูลค่าเพิ่มเท่านั้น
4. โปรแกรมนี้จัดทำขึ้นเพื่อความสะดวกในการหาค่า Factor F เบื้องต้น **โปรดตรวจสอบกับตารางต้นฉบับก่อนใช้อ้างอิงอย่างเป็นทางการ** ผู้จัดทำไม่รับผิดชอบต่อความเสียหายที่เกิดจากการนำผลลัพธ์ไปใช้
